# 🦊 About Me

Hey, I'm **Thiyagu** — a full-stack engineer based in Tokyo with 3.5+ years of experience building production web applications. By day I ship features in **Vue 3, TypeScript, Java Spring Boot, and PostgreSQL** — working daily in both **Japanese and English** (JLPT N2 in progress).

Outside work, I run **[KitsuneChaos](https://kitsunechaos.com)** — an experimental platform where I build:

- ⚡ Physics & electronics simulations
- 🧠 AI-assisted developer tooling
- 🎨 Creative workflow systems
- 🧪 Browser-based experiments

My background is an MSc in Physics, and my work sits at the intersection of:

```txt
TypeScript × Physics × AI × Interactive Learning
```
